# Study-06 — 쇼핑 리스트 앱

Vibe Coding 학습 프로젝트 — 순수 HTML/CSS/JS로 만든 쇼핑 리스트 웹 앱

## 폴더 구조

```
Study-06/
├── shopping-list.html   # 메인 앱 (HTML + CSS + JS 단일 파일)
├── .gitignore
└── README.md
```

## 주요 기능

- 항목 추가 / 삭제
- 체크 완료 처리 (취소선 + 녹색 표시)
- 완료된 항목 일괄 삭제
- `localStorage`로 새로고침 후에도 데이터 유지

## 실행 방법

별도 빌드 없이 `shopping-list.html`을 브라우저에서 바로 열면 됩니다.
